# Academic Writing

Use this for manuscript work inside a single project repo.

## Required companion skills

- `codex-safety`
- `session-discipline`
- `rigor`
- `lit-review` when literature claims are involved
- `empirical-coding-discipline` when numbers come from code

## Protocol

1. Identify the authoritative manuscript source file.
2. Stay read-only until the user explicitly authorizes edits.
3. For non-trivial changes, make a short revision plan first.
4. Verify each factual, numeric, and citation claim before writing it.
5. After edits, verify the artifact in the cheapest reliable way available.

## Suggested outputs

- section rewrite memo
- revision plan
- response-to-referees draft
- claim-verification checklist
- pre-submission audit
