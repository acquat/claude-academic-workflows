# Coding SNDS

## Mandatory posture

- `codex-safety`
- `rigor`
- `empirical-coding-discipline`

## Core rules

1. Treat data-security and export rules as binding constraints.
2. Never move from coding to export advice without checking the disclosure rule in force.
3. Verify joins, counts, and table structure after each material step.
4. Ask before reading any enclave-adjacent material outside the local repo.

- SAS review memo
- export-compliance checklist
- join-risk audit
- project-specific coding protocol
