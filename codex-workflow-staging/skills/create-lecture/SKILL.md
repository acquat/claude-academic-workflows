# Create Lecture

## Safety rules

1. Stay inside the active course repo unless the user authorizes another materials folder.
2. Do not write slides until the user has approved the structure.
3. Do not bulk-draft a full lecture without iterative check-ins.

## Workflow

1. Read the course knowledge base, prior lecture ending, and relevant source papers.
2. Propose the pedagogical goal and lecture arc.
3. Map notation to course conventions before introducing symbols.
4. Draft in small batches.
5. Verify citations, examples, and visual coherence.

## Hard constraints

- motivation before formalism
- no notation drift
- no unverified citations
- no direct edits outside user-approved scope
