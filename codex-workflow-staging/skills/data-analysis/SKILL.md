# Data Analysis

## Mandatory posture

- `codex-safety`
- `rigor`
- `empirical-coding-discipline`

## Workflow

1. Clarify the analytical question and data source.
2. Set up a script-based analysis pipeline.
3. Run exploratory checks before estimation.
4. Build main specifications with documented standard-error choices.
5. Export tables, figures, and reusable objects.
6. Review the script and results before presenting conclusions.

## Constraint

Do not silently choose sample restrictions, clustering levels, or definitions when multiple valid options exist.
