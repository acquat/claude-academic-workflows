# File Claim

## Safety rules

1. Do not modify forms, ledgers, or folder contents unless explicitly authorized.
2. Stop on critical policy violations rather than forcing a filing workflow through.
3. Preserve an audit trail of rates, totals, and rule checks.

## Workflow

1. Validate the submission folder contents.
2. Inventory and categorize receipts.
3. Convert non-home-currency items.
4. Run a compliance check.
5. Prepare a print-ready summary and surface blockers.
