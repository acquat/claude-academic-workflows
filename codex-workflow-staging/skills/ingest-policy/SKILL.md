# Ingest Policy

## Safety rules

1. Never invent policy rules.
2. Preserve ambiguity explicitly with confirmation markers.
3. Do not overwrite an existing rulebook without user approval.

## Workflow

1. Locate and extract the policy text.
2. Organize rules by category, severity, and citation.
3. Surface ambiguities before any write.
4. Write the rulebook only after sign-off.
