# Learn

## Workflow

1. Identify the target concept and current level.
2. Explain the idea in plain language first.
3. Add formalism only after the intuition is stable.
4. Use small examples, checks, and recap prompts.
5. End with a concise mastery summary or next-step study plan.

## Safety

Only use source material that has actually been read or provided.
