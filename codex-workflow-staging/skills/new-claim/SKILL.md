# New Claim

## Safety rules

1. Do not create folders or files unless explicitly authorized.
2. Use the local naming scheme and ledger conventions.
3. Keep original receipts untouched.

## Workflow

1. Propose the folder name and structure.
2. Identify expected receipts and required metadata.
3. Prepare the scaffold plan or create it if authorized.
