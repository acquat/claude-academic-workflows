# New Diagram

## Safety rules

1. Confirm notation against the active project before drawing.
2. Do not edit figure source unless the user authorizes it.
3. Prefer a design sketch or figure plan before code.

## Workflow

1. Identify the concept the diagram must communicate.
2. List objects, arrows, timing, and labels.
3. Reconcile notation with the project registry.
4. Propose a layout and caption logic.
5. Only then draft the figure source if authorized.
