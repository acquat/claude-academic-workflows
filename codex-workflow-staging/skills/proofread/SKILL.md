# Proofread

## Safety rules

1. Do not edit the file unless explicitly asked.
2. Preserve meaning, claims, and the author's voice.
3. Flag factual uncertainty separately from proofreading issues.

## Output

- marked issues
- concise rewrite suggestions
- optional patch only if authorized
