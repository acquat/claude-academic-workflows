# Reading List

## Safety rules

1. Never fabricate citations.
2. Prefer already-vetted course materials before broader search.
3. Do not write the list file unless explicitly authorized.

## Workflow

1. Anchor on course materials already in the repo.
2. Fill gaps with verified sources.
3. Separate core readings from extensions.
4. Add short annotations and prerequisite guidance.
