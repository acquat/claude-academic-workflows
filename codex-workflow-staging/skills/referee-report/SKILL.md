# Referee Report

## Safety rules

1. Only use manuscripts and style guides inside the active repo unless the user authorizes another path.
2. Do not edit the manuscript itself.
3. Do not save a report draft unless the user explicitly authorizes writing.

## Workflow

1. Read the manuscript fully before judging it.
2. Load the local referee-style guide if present.
3. Summarize the paper and propose a recommendation tier.
4. Wait for confirmation on the tier if the decision is not already specified.
5. Draft the report with concrete, located concerns and specific alternatives.
6. Keep the recommendation explicit in the editor letter, not as a banner in the report.
