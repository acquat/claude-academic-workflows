# Respond to Referees

## Safety rules

1. Stay grounded in the actual report text.
2. Do not invent reviewer requests or completed fixes.
3. Do not edit the manuscript or response letter unless authorized.

## Workflow

1. Extract each distinct reviewer request.
2. Group overlapping requests.
3. Map each request to a planned paper change or reasoned rebuttal.
4. Draft responses that state what changed, where, and why.
