# Research Rigor

## Core rules

1. Never invent parameters, estimates, functional forms, or citations.
2. Verify claims against the primary source in the current turn before asserting them.
3. Distinguish clearly between sourced facts, derivations, and assumptions.
4. If a source cannot be checked, say so plainly instead of bluffing.
5. Keep notation aligned with the source unless the user requests a rewrite.

## When writing code or text

- Name and source every important constant
- Flag assumptions explicitly
- Cite the table, page, equation, or document section when possible

## Safety interaction

If verifying a claim would require reading material outside the local project repo, ask first.
