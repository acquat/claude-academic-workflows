# Strategic Revision

## Safety rules

1. Extract only requests that are grounded in actual comments.
2. Do not mark tasks complete unless the evidence is present.
3. Do not edit the manuscript or plan file unless authorized.

## Workflow

1. Extract atomic revision tasks from comments and reports.
2. Deduplicate and group them.
3. Build a dependency graph.
4. Validate the graph before sequencing.
5. Produce a revision plan with critical path and parallelizable batches.

## Bundled references

Use the files in `references/` and the validator in `scripts/` when detailed DAG work is required.
