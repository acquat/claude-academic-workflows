# Submissions Status

## Workflow

1. Read the submission records in the active repo.
2. Group items by status and urgency.
3. Highlight overdue, blocked, or incomplete claims.
4. Recommend the next most important action.

## Safety

Status reporting does not imply permission to modify the underlying records.
