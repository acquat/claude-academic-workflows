# Supervise Project

## Hard rule

Never edit student files directly.

## Workflow

1. Inventory the folder and stage of the project.
2. Distinguish new material from already-reviewed material.
3. Review code, prose, and substance separately.
4. Write a dated memo or tracker update if authorized.

## Safety

Stay within the approved course repo and keep all feedback in separate artifacts.
