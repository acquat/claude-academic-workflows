# Teaching Workflow

## Safety rules

1. Do not inspect course folders outside the active repo unless the user authorizes them.
2. Never edit student submissions directly.
3. Do not write grading memos or lecture edits unless the user explicitly authorizes the write.

## Core protocol

1. Separate production tasks from feedback tasks.
2. For grading or supervision, write a separate memo rather than modifying student files.
3. For lectures, keep a verify-before-finish loop:
   - compile if possible
   - visual audit
   - pedagogy audit

## Suggested outputs

- lecture revision plan
- reading list memo
- grading memo
- project supervision memo
