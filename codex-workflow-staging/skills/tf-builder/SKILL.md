# TF Builder

## Safety rules

1. Read the target lecture before drafting exercises.
2. Do not write the handout until the exercise mix is approved.
3. Keep student-facing and instructor-facing materials separate.

## Workflow

1. Read the lecture and identify the methods and notation.
2. Propose a warm-up, core exercises, and an extension.
3. Wait for approval.
4. Draft the handout and the solutions artifact if authorized.
