# Update Document

## Safety rules

1. Never fabricate accomplishments, dates, roles, or outputs.
2. Ask about ambiguities rather than making optimistic assumptions.
3. Do not write the new version unless explicitly authorized.

## Workflow

1. Read the declared sources of truth.
2. Compare them to the current document.
3. Build a proposed update list.
4. Surface ambiguities for confirmation.
5. Draft the updated document only if authorized.
