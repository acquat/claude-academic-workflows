# Writing Style Guide

## Safety rules

1. Do not edit prose unless explicitly authorized.
2. Preserve factual accuracy over stylistic imitation.
3. Do not force domain-specific vocabulary where it does not fit.

## Core voice rules

- open with the claim
- use first-person assertion where appropriate
- lead intuition before formalism
- use concrete anchors after abstract claims
- keep technical caveats in footnotes when relevant
